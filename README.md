# Blinq

Web App zum automatischen Aussortieren von Fotos (Hochzeit, Event, Sport, Studio), für iPhone und iPad.

* Hosting: Cloudflare Pages, Build Befehl leer, Ausgabeordner `/`
* Aufs Handy: Link in Safari öffnen, Teilen, „Zum Home Bildschirm“
* Alles läuft im Browser. Fotos bleiben auf dem Gerät (IndexedDB). Nur die optionale KI Prüfung schickt verkleinerte Bilder an die Claude API, mit dem eigenen Schlüssel.
